# Fragrance Finder — project status

Last reviewed: 1 October 2026

## Purpose

Help users discover fragrances through a curated UK dataset and transparent similarity/recommendation logic.

## Current state

A responsive static prototype exists with 100 launch fragrances and precomputed comparison relationships. Retailer-product imagery/links are handled through a separate temporary adapter.

The product does not currently have a defined active commercial milestone.

## What works

- 50 perfumes and 50 men's fragrances.
- Structured fragrance profiles.
- Five comparable recommendations per scent.
- 500 precomputed comparison relationships.
- Static responsive UI.
- Temporary retailer-product adapter.
- Vercel and GitHub Pages deployment paths.

## Live / deployment status

Deployment paths exist, but no active commercial/public launch is currently evidenced.

## Current milestone

**Paused. Decide whether Fragrance Finder should become a real affiliate/discovery product before further build-out.**

## Key decisions

- Match scoring is transparent guidance, not scientific prediction.
- No dupe/performance guarantee.
- Core fragrance data stays separate from retailer-product feeds.

## Current blockers / dependencies

- Commercial/business model.
- Affiliate strategy.
- Sustainable product-feed source and permissions.
- Decision on whether the curated 100-fragrance launch dataset is enough for the intended product.

## Next actions if resumed

1. Decide the commercial objective.
2. Choose/validate an affiliate or retailer-feed approach.
3. Confirm data/image/link usage rights.
4. Define the minimum launch catalogue.
5. Only then prioritise product/UI expansion.

## Deferred / out of scope

Avoid expanding catalogues, accounts, social features or recommendation complexity until the commercial path is clear.

## Handoff notes

Treat this as a preserved prototype until the business model is deliberately reactivated.
